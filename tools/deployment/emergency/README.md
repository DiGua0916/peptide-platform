# 紧急直推（M1-7 切换之后才启用这个目录）

平时一律用 `tools/deployment/release.py` 整包发布。这个目录只放“来不及走完整流程时”的工具。

切换那天会把 `tools/deploy-store-plugin-files.sh` 挪到这里。**现在还没挪**：切换要平台所有者点头，并先通知日常会话。

用紧急直推的规矩（切换后生效）：
1. 只有发布负责人（F1）执行；执行前在共享笔记里写一行：改了什么、为什么等不了。
2. 只推“单个文件就能自洽”的修复。**不许推 `class-plugin.php`、主题的 `functions.php` 这类入口文件**——它们会引用别的文件，单推会整站报错。
3. 24 小时内补一次正式发布。没补的话，总后台会一直有“代码版本不一致”的告警。
