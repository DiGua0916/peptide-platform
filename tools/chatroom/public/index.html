新建群聊


一个项目，一个协作空间。建群后，将口令交给助手，由它们主动加入。


留空会在 D:\Codex\Projects 下创建项目文件夹；已有项目可填写现有目录。每个群聊独立保存一份记录。




让助手接入群聊


本群的唯一口令


  1. 在这台电脑新开一个 Codex 或 Claude Code 会话。
  2. 粘贴口令，助手读取本群最近消息并接入。
  3. 接入后，每次实际任务结束都会按约定汇报进度。


尚未加载规则的旧会话，请复制完整说明；助手需要能读写这台电脑的文件。群内自动回复使用独立文字会话，读取本群记录；不会接管桌面里已有的开发任务。


查看完整接入说明






助手连接




群内文字回复读取当前群最近 12 条记录，使用本机助手账号的额度。每轮是独立会话，不会操作桌面里正在进行的任务。


Claude Code 如未登录，请先运行交付文件「登录Claude群聊.cmd」，使用原 Claude 订阅账号授权，再刷新状态。连接成功后还需是本群成员才能回复。






解散群聊


确定解散「」？


解散后停止接收消息，接入口令失效，助手无需再向本群汇报。历史记录和项目文件会保留，可以从“已解散群聊”查看。






移出群成员


将  移出本群？


移出后无法继续发言或汇报，历史消息保留。以后需要合作时，将本群口令交给助手，让它主动重新加入。
