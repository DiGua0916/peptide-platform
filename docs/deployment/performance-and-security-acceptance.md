# 买家访问性能与安全联合验收

2026-11-01 · Codex。用户要求“安全性高、性能好、客户访问不能卡顿”。当前仅制定配置与验收目标，**没有实测服务器、没有对本地/线上业务发起压测，没有取得容量结论**。购买独享vCPU、较大内存和边缘服务不能保证任意网络/攻击下零延迟。

## 1. 什么叫流畅

以下采用 [Google Core Web Vitals官方标准](https://web.dev/articles/defining-core-web-vitals-thresholds)，按**真实访问的第75百分位**、手机/电脑及目标地区分别观察，而非只看一次最快成绩：

| 指标 | 目标 | 用户感受 |
| --- | --- | --- |
| LCP | ≤2.5秒 | 主体内容及时显示 |
| INP | ≤200毫秒 | 点击、展开等操作及时产生画面反馈 |
| CLS | ≤0.1 | 页面加载时布局少跳动 |

它们是总体用户体验目标，不是所有用户每一次都可达。INP也不等于完整支付/加购的网络耗时。上线前用可重复的手机网络/CPU环境、浏览器交互及美国多个地区实测定位瓶颈；上线后在达到足够真实样本时再报告现场p75，实验室模拟不能冒充真实用户数据。

补充工程候选门槛（本项目建议，非Google标准、未由用户确认为SLA）：同区预上线负载下，本站处理的商品/筛选/加购/购物车/结账准备请求p95≤1.5秒，HTTP 5xx与意外超时≤0.1%。统计必须包含失败请求和完整耗时，不剔除慢请求美化结果；收款供应商、三方验证、人为操作的等待单独计时，不强套此上限。具体正式门槛按实际网络/基线与业务高峰确定；超标先定位再决定扩容。

## 2. 必须分开测的流量

- 首页、专辑和商品页：冷缓存/热缓存、首次图片载入、真实首屏大图、规格选择、筛选/排序、手机展开与菜单。
- 登录/未登录：账户、积分、订单、授权报告。购物车、结账、支付、个性化页面和REST不做共享整页缓存；不同用户不能看到对方资料。
- 广告承接：真实落地路径、正常查询参数、来源跳转和追踪脚本；测正常消费者，不按审核身份替换业务内容。
- SEO核心：公开页面索引可达；真实搜索引擎的验证与限流同时可用，不能因防爬把正常搜索/买家统一挑战。
- HQ与店铺：人员登录、店铺签名请求、异步回写、定时备份及正常后台操作；前台高峰时后台大导出/备份不抢尽CPU/内存/IO。
- 第三方：支付、邮件、搜索、像素、字体/视频脚本。未接入的仍空置；测试记录明确第三方等待，不把无限同步重试留在买家请求中。

## 3. 怎么找慢点

从美国东部/中部/西部测真实域名，记录DNS、TCP/TLS、TTFB、内容下载及浏览器主线程长任务；按区域分组，不只报全球均值。未来欧洲/南美/中东在有实际流量前增加探测，动态结账距离仍受源站/数据库影响。

同时监测PHP-FPM队列/活动进程/慢日志、CPU/steal、内存/OOM/swap、磁盘IO/容量、MySQL慢查询/连接和持锁时间、缓存命中率及HQ待回写积压。慢日志先脱敏，不保存SQL参数里的客户资料或完整query/token。OPcache开启并核配置，FPM worker数按实测单进程峰值与数据库/系统预留内存预算计算，不盲开到CPU数倍。

图片使用正确尺寸、现代格式与浏览器响应式加载，首屏关键图与屏外图片区别处理；脚本按页面加载，减少阻塞和不必要第三方。对象缓存先核插件兼容并明确每实例隔离/失效，Redis不对公网开放；它不是业务数据库，也不能掩盖错误权限/过期订单数据。任何前端实现修改仍交由前端角色，当前阶段没有擅改主题或装修草稿。

仅缓存可安全公开的响应；启用商品页缓存前验证Woo会话、价格策略、登入状态和优惠参数；账户/订单/报告内容的权限与缓存隔离优先于跑分。错误地缓存结账即使速度很快也不能通过验收。

## 4. 负载与扩容

并发用户数、到达率、会话长度、每分钟下单数尚未给出，**不承诺此套餐能承载某个访客/订单数量**。先取得广告预估/现有流量，测一次正常基线后，用隔离预上线实例和合成账户数据分阶段递增到目标峰值与短时突增，并测持续运行/冷缓存、计划任务同时运行的情况。

测试需明确最大速率、持续时间、超时和停止条件，采集请求率/完成率/p50/p95/p99/错误率/资源曲线；发现连续超时、队列增长、资源耗尽即停止，不在正常生产客户上试极限。压测不连接真实收款、发信、外部履约或提交真实客户资料；合成内容留隔离实例，不回流正式库。

瓶颈在PHP/SQL先修查询/索引/插件调用和进程预算；持续CPU瓶颈再垂直升配，数据库或磁盘瓶颈按实际证据处理。增加多个应用节点前解决共享上传、会话/缓存、单一writer和任务互斥；不要仅复制VM就宣称自动高可用。Managed MySQL或双节点故障转移须另验证当前同库writer/独立连接语义、TLS/权限、failover后在途任务；本轮未选购，也不将单台VM称为高可用。

## 5. 安全与体验一起通过

人员MFA、精确机器认证、源站区域身份验证、系统修补、站点/账号/库隔离、日志脱敏、异地加密备份和恢复实测按[生产手册](production-runbook.md)落地。独享CPU本身不能防漏洞、钓鱼、撞库或数据导出；边缘规则仍须保留正常买家与精确回调。

Cloudflare套餐[价格](https://www.cloudflare.com/plans/)：Pro月付$25/区域；Business月付$250/区域、年付折算$200。Business提供更高档服务/功能选择，但[其机器人防护是Super Bot Fight Mode](https://developers.cloudflare.com/bots/plans/biz-and-ent/)，不是Enterprise Bot Management。按所需功能/支持和报价决定，不拿套餐名称保证更快、更安全或任意攻击下不停机。

模拟异常请求只在受控实例验证：错误签名/重复事件、未授权报告/跨店访问、撞库限流以及正常消费者操作不能被误伤；不对公网第三方实施攻击或流量测试。安全挑战、缓存和限流上线后同步复测LCP/交互与支付接口，不能用放宽鉴权或关闭TLS换速度。

最终收据须同时有：硬件与源码版本、各地区/设备测试条件、页面与API分组百分位、负载模型、失败请求、资源曲线、安全例外/权限验证、恢复计时及明确未通过项。没有这些证据时只称“已准备配置”，不称“已实现不卡顿”。
