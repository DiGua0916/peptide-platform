## 二、线上已有功能保持原样的证据（同一份数据逐页比对）

**做法**

- 本机一次性副本（SQLite，WordPress 7.1.4 + WooCommerce 11.2.1），不是 MySQL 沙盒。
- 先装线上的代码（主线 `4a161de` 的导出）：建两个投手账号（一个普通，一个“首次登录要改密码”），用线上代码的表单保存过一次店铺信息；配好满减活动、优惠码、运费方案、热销库存；给订单 #104 加上 `hang-` 订单号。
- 用线上代码取一遍页面，再取一遍（看两次之间的“噪音”），然后换成这个分支的代码、同一个数据库，再取一遍，逐行比。
- 比之前统一去掉每次都会变的东西：nonce、静态文件版本号、时间戳和时间、随机编号、浏览器来源地址、主题文件指纹（主题任何文件一变指纹就变，属于版本号一类）。去掉之后，**线上代码自己取两遍是 44 个地址全部一致**，说明剩下的差异不是噪音。

**11-14 方案 A 改完后重比的部分**（同一个副本、同一个库，开关都关；线上代码 = `4a161de` 的导出，换代码后重启本机服务器）：

- 访客的首页、两个商品落地页（简单、多规格）、商品链接（仍 302 到 `/?vc_product=<ID>`）、购物车：去掉噪音后逐行一致。购物车有一行 `wcSettings` 编码后不同，解码逐项比是一致的（每次请求的 nonce）。
- 接口：`POST /peptide/v1/order-lookup` 线上 200（“没找到”），分支 404 `rest_no_route`；`GET /peptide/v1/buyer/status` 分支 404。线上物流面板的 `POST /peptide/v1/track/lookup` 两边都在。
- 年龄确认和商品弹窗谁在上面：首次进站（清掉 `pcAgeOk`）打开商品链接，两个弹窗都打开，**商品弹窗在上、18+ 确认在下**。线上代码 3 次、分支代码 3 次（简单和多规格商品），结果相同，所以按所有者“以线上为准”不用改。

**浏览器里真正打开商品弹窗之后的样子**（脚本跑完、价格和活动都出来之后取整个弹窗）：简单商品的落地页、商品链接两处一致。多规格商品的落地页有一处不同：弹窗里的库存短句（“50 in stock”）在一边显示、另一边不显示。查下来**不是这次的改动造成的**：

- 两边的数据库数据一样，显示这句的脚本（`product-dialog-meta.js`）两边也一样。
- 线上代码本身就两种结果都有：在页面里加一段只记录事件的小脚本，线上代码就显示这句、分支代码反而不显示，和不加时正好相反。
- 原因是时序：这句只在“规格匹配成功后刷新一次”时取 WooCommerce 画出来的库存，而 WooCommerce 画库存比“匹配成功”晚约 300 毫秒，刷新落在前面就是空的。这是主题里原有的问题（主题归 F5），**这次没有改**，记在第五节，修不修另报。

**开关打开时**（另外看过，不算“线上原样”的证据）：`pc_buyer_extras` 打开后订单列表出现导出表单、能下载 CSV、多出“退款状态”一列（11-14 起，来源、物流单号就是线上那两列），店铺信息出现客服按钮勾选框；`pc_buyer_no_palette` 打开后 WordPress 的命令面板（列菜单的那部分）不再加载。主题三个开关在 11-12、11-13 的交接里各自验过。

**商品链接 302 跳首页，和 FE-02 的冲突**（11-14 所有者已定：302 + 弹窗不动，FE-02 先不开。下面是当时的分析，留作以后要做真正商品页时参考）

- 现在（主线、生产 s0010、沙盒都一样）：商品链接 `/product/<slug>/` 一律 302 到 `/?vc_product=<ID>#vc-products`，也就是首页 + 自动打开这件商品的弹窗。弹窗打不开时，顾客看到的就是首页。
- 打不开的一个已知原因已在这次修掉：页面在后台加载（在新标签页里打开广告链接、应用内浏览器预加载）时，线上代码直接放弃打开弹窗。别的原因（设备不支持弹窗入口、商品下架）仍然会落到首页。
- FE-02 做的是反方向：弹窗打开后把地址栏改成 `/product/<slug>/`，方便顾客复制分享；它依赖“这个地址会 302 回首页 + 弹窗”。所以两件事绑在一起：
  - 如果要改 302（例如 `/product/<slug>/` 改成真正的商品页，或者落地不再经过首页），FE-02 写进地址栏的地址、以及“打不开时显示什么”都要同一次一起改，否则分享出去的链接和顾客当时看到的不是同一个页面。
  - 反过来，FE-02 打开后每个分享链接都要多走一次 302（11-12 本机量过：经过 302 时弹窗打开 776 毫秒，直接打开落地页 490 毫秒，多约 0.3 秒；本机不限速，真机会更多）。
- 建议：先保持 302 + 弹窗（广告落地页的满减券、热销、运费、离开挽回都在弹窗里，已逐个验过）；FE-02 先不开，等所有者定了“商品链接要不要有真正的商品页”再一起做。商品页这一层（302 本身）是主线的入口代码，不在 F5 名下；FE-02 在 F5 名下。
