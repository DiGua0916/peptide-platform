## 〇、原则：和线上已有功能重叠的，一律以线上为准

平台所有者 2026-11-14 定的通用原则（原话）：“以后遇上类似的问题，优先用站点已经存在的，因为那个是我亲自加的，而不是用你这块后面自己写的，你的是没经历过测试的”。

所以这次发布的做法是：凡是和线上已有功能重叠的地方，开关关着时**完全照线上的写法**；F3 后来写的版本只放在默认关闭的开关后面，或者根本不走到。逐项核对如下：
