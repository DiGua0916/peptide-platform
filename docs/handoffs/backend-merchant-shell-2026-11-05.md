# Merchant persistent-shell trial

User explicitly requests applying the previously discussed partial-navigation architecture and seeing it online. Source inspection finds native WordPress/Woo controllers and long-running report closures without a uniform disposal contract. Instead of introducing Turbo Drive globally and replaying their scripts in a shared Window, this trial uses the same persistent-chrome architecture with browser-owned same-origin document isolation. **No Turbo library is installed and this is not a same-document SPA.** Outer menu/header remain; supported content pages load into a fresh same-origin iframe, replacing the previous document only when loaded. The browser destroys old document requests/timers/listeners. No HTML/credentials are stored in browser caches/local storage by this feature. Existing authentication, capabilities, nonce checking and host-only cookies remain native.

Entry is restricted to authenticated manage_woocommerce GET dashboard/data landing URLs without extra query fields; no direct editor/POST/action page is wrapped. The actual screen load hook renders header/isolated-content/footer, and removes dashboard/data controller enqueue from the outer document. Inner requests use pc_embed=1 or browser Sec-Fetch-Dest=iframe solely as layout hints, never permissions. Admin chrome is hidden inside content documents. An explicit route allowlist permits ordinary merchant lists/report pages, disallows foreign origins, action/nonce/export/unknown/duplicate params and editor routes. Unsupported links use ordinary top-level navigation; native POST submissions target the top page. Dirty POST-form signatures prompt before supported navigation; no form values are transmitted by navigation. Parent history uses canonical URLs, no embedding marker; cancelled Back retains the current document. Native forms/editors and direct GET URLs remain available.

Files: Workspace hook, new Workspace_Shell PHP, isolated workspace-shell.js/css, and skip old native feedback on outer shell. Syntax checks and 21 actual-JS route/dirty-signature assertions pass. Production rollout and actual browser behavior are pending at this proposal checkpoint; do not call the whole merchant admin converted or measured faster yet.
