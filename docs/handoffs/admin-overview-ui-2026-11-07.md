# 后台概览 UI 优化第一步 — 2026-11-07

用户反馈："概览的 UI 太大了，一打开 UI 都崩了"。范围：商家后台（s0001）的仪表盘和总后台（HQ）的概览。只改样式和显示，不动数据。

## 诊断（正式站只读实测，窗口宽度 1121 / 1366 / 1920）

- 商家后台：
  - 1121 宽时页面高 2533px（约 3.9 屏），转化卡片 967px，漏斗和趋势图上下叠放；1366 宽时约 3.2 屏；
  - 1920 宽时右侧栏只有 264px，内容挤成一团；数字 26–30px。
- 总后台：
  - 1920 宽时 7 天销售图高 638px，店铺列表被推出第一屏；
  - 1121 宽时店铺网址拆成两行，"进入后台"按钮折成两行。
- 原因：
  - 正式站实际用的是工作台样式表 `overview-workspace.css`：右侧栏写死 264px；按 iframe 宽度判断（`@media max-width:1400px`），所以浏览器窗口窄于约 1620px 就变单列；卡片窄于 820px 时漏斗和图上下叠放；
  - 趋势图用固定比例的 SVG，宽度 100%，屏幕越宽图越高；
  - HQ 的工作台样式去掉了图表的 960px 宽度上限；
  - `#wpbody-content .button` 强制所有按钮允许换行。

## 改动（提交 02e5e6d）

- `peptide-core/assets/overview-workspace.css`：
  - 默认单列，概览本身宽度 ≥1240px 时再加 320px 右侧栏（用容器查询，不看浏览器宽度）；
  - 漏斗和趋势图在卡片宽度 ≥680px 时左右并排；
  - 数字 22–24px（原来 25–30px）。
- `peptide-core/assets/overview.css`：
  - 固定字号（不再跟着屏幕宽度变大）；
  - 不在工作台里时同样按容器宽度排版；
  - 访客列表最高 420px，超出部分在卡片内滚动。
- `peptide-core/assets/overview.js`：趋势图按实际像素宽度绘制，高度固定 240px，窗口大小变化时重新绘制。
- `peptide-hq/assets/hq-workspace.css`：
  - 销售图最高 240px（保持比例）；
  - 店铺网址和"进入后台"按钮不换行，空间不够时表格可以左右滑动。
