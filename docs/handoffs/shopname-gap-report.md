## 1. 最重要：装修编辑器（“积木装修”）

### Shopname 的做法

- 编辑器分三栏：中间是实时预览（可以切换电脑和手机），右侧是**积木列表**，最右是当前积木的**设置面板**。
- 每块积木都可以拖动排序、隐藏（眼睛图标）、删除，也可以在下面“添加积木块”。
- 改完点“发布”才会生效，另有“撤回”。
- 可以编辑的页面：首页、商品详情页、专辑列表、专辑详情、活动专题、搜索页、优惠码页、满减页、博客列表、个人中心、404 页和自定义页面。
- 设置面板以轮播图为例：
  - 播放：自动轮播、分页器、轮播秒数、图片高度、标题字号；
  - 每一张幻灯片：电脑图、手机图、ALT、布局（9 个位置）、二级标题、标题、按钮文字、跳转链接、蒙层颜色、文字颜色、按钮颜色。
- “全局配置”的内容：
  - 常规：积木间距、内容宽度、按钮圆角、转场动画；
  - 颜色：背景、标题、正文、现价、原价、主次按钮；
  - 字体：标题和正文的字体、字号、字间距；
  - 商品：折扣标签、评分、色卡、库存文案、快速预览、第二张图悬停等；
  - 其他：评论设置、社交媒体链接、账户中心。

### 积木库（共 70 多种）对照 WordPress 区块编辑器

| 订单履约看板、捐款/小费、AI 商品瀑布流、热点购物 | 不需要，或者不建议 | ⛔/可选 |

**结论**：这就是你要的“模块化”，和 EDIT-BLOCKS-01（改成区块编辑器）完全一致。

- WordPress 核心和 WooCommerce 已经覆盖了大约一半的积木。
- 缺的主要是**轮播图、商品轮播或选项卡、几种展示型积木**，需要 Codex 做成自定义区块或 pattern。
- “全局配置”对应 WordPress 的**全局样式**（theme.json 里的颜色、字体、间距）。Codex 需要把主题现在写死的颜色和字号接到 theme.json 上，你才能在后台修改。
- 和 Shopname 的差别：WordPress 没有“草稿 → 发布”两步走，页面改完点“更新”就立刻生效。可以先“保存草稿”或“预览”，修订记录里也能回退到旧版本。

## 4. 我在前台看到的问题（顺便提醒）

1. **页脚有“Dosage Calculator”（剂量计算器）**。这属于用法或剂量指导，和“仅供研究使用”的定位冲突，是支付商和监管最容易抓的点。VialCove 不要照搬，建议 Shopname 店里也去掉。
2. **“Best Seller”和“Product COAs”**：只有真实销量和真实检测报告才能这么写。我们的批次报告功能就是为真实 COA 准备的。
3. 原模板来自别人的店（Helixora），复制过来的文案和图片要确认有使用权。

## 5. 建议的补齐顺序

| 优先级 | 内容 | 谁做 |
|---|---|---|
| **P0 上线必须** | ① EDIT-BLOCKS-01 区块编辑（含轮播自定义区块、全局样式） | Codex 主做，Claude 做动态区块 |
| | ② 真实支付和运费（等你提供） | 你 + Claude 配置 |
| | ③ 物流单号追踪 | Claude |
| | ④ SEO 插件（Rank Math 或 Yoast） | 你同意后由 Claude 安装配置 |
| | ⑤ GA4 / 广告像素 | Claude（后台设置）+ Codex（前台埋点） |
| | ⑥ 客服浮动按钮 | Codex 做按钮 + Claude 做设置 |
| **P1 运营增强** | 弃单挽回和订阅邮件、满减或买多件优惠、操作日志、自定义脚本入口、信任徽章、批量改价工具 | 主要是 Claude |
| **P2 以后** | 收藏、积分、常用话术、地址自动填充、晒图评论 | 视需要 |
| **不做** | 斗篷、虚拟物流、假倒计时或假购买弹窗、剂量计算器、捐款/小费 | — |

**需要你决定**：
1. P0 的顺序。我建议先做 ③ 物流追踪和 ⑥ 客服按钮，这两个不依赖外部账号。
2. SEO 插件选 Rank Math 还是 Yoast。安装插件需要你同意。
3. 邮件服务用哪家（影响弃单挽回和订阅）。
