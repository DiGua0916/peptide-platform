2026-11-02 · Codex · CART-ACTIVITY-INSTALL-01

用户确认黄豆吹派对纸卷、纸卷末端小烟花后明确要求“装上吧”。本轮在 Peptide Core 自己的购物车挂载点实现显示组件，主题与前端工作树没有改动。它已经消费真实 Woo Store API 数据，不再只是任务目录中的模拟预览。

## 当前行为

- 只在购物车页面加载，不进入首页、商品页、全站抽屉或结账。
- 读取原 `extensions.peptide_core.activity_listener`，沿用活动资格、实际费用优惠、节点、差额、规则身份；没有新的折扣、加购或订单 API。
- 内容只保留当前计量值、距离下一档差额、门槛和优惠标记。没有组件内营销标题或说明段落；后台标题作为可访问名称。
- 黄豆缩小放在档位上方，纸卷展开、停留、卷回，共2.8秒；展开完成后16粒小烟花从卷头末端一次散开，靠右时朝左吹。
- **用户最新决定覆盖旧每档一次行为：每个变化后的有效达标购物车状态都可播放当前最高档，不设置“该档已播过”锁。** 同档继续增加、仍合资格的减少、优惠状态改变后确有正优惠均可再播。相同 stateKey 的重复通知合并；首次载入、规则变化、失败恢复静态建立基线，空车/无优惠/过期不庆祝。
- 手机或组件宽度≤600时档位保持一条横线，金额提示在下方，上面只留黄豆表演空间。标签等距，进度按服务端百分比在对应视觉节点间插值，语义进度值和所有钱数仍来自服务器；不计算或修改优惠。320px三档无需滚动/字体缩放；超过可用宽度的更多档位仅在组件内横向滚动。较宽组件保留比例位置与长文案布局。
- 支持减少动态、离屏/隐藏停止、重复事件合并、加载失败降级；动画不阻塞原生购物车按钮。

## 源码与挂载

- `includes/activity/class-mount.php`：购物车专用资源加载，公开配置JSON追加 `blockCart`、`mascotUrl`、`labels`，保留单次输出。没有把客户金额、身份、商品或nonce写进SSR。
- `assets/activity-listener.js`：原生 Blocks store订阅，经典购物车事件合并刷新，只读同源GET；pending中作废旧GET，序号和store epoch拒绝过期回包；缓存的相同store stateKey不复活已关闭状态。没有localStorage、购物车写请求或客户日志。
- `assets/activity-listener.css`：组件作用域内样式与横排适配；不覆盖全局主题。
- `assets/images/activity-listener-bean.png`：用户批准的原创生成UI资源，原文件736057字节，SHA256 `e80253cee96d764a4e6d77a61c3ecf12aa4734e261faab3911a2bfe5b4826770`。它是插件UI源码资源，不是客户媒体或店铺上传资料。

正式店铺入口仍为应用中心 `admin.php?page=pc-apps&app=activity-listener`。应用配置与活动规则没有本轮自动变更：原站只读核对已应用为启用/活动10980/revision1；默认新安装仍保持关闭。前端窗口不要再为同一挂载点初始化另一个renderer。
