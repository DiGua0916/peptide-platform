### 1.4 比对的局限

- 本机是 SQLite，不是 MySQL。两处 SQLite 和 MySQL 不一样的函数（`GREATEST`、`JSON_UNQUOTE`）和这次新发现的 `LPAD` 在本机用垫片补上，A、B 用的是同一套垫片。

- 页面只比了服务端输出（页面外壳和交给脚本的配置），没有在浏览器里截图比；CSS 的变化是确定的，写在上表里。
