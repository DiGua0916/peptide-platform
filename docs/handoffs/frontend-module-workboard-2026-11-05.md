## 并行方式：一人一包，按文件避让

建议其他窗口选 **M03商品弹窗、M06结账、M07 COA库** 中的一个完整包。本窗口锁定M05；刚改过的M01浮球/M02活动条先保持，避免重复返工。M08全局动效与M09跟踪属于横切模块，要等各页面稳定再做。

**目前真实代码不是“每个子模块一个独立文件”。** `live-cart-experience.js/.css`、`home-quick-view.php`、`home-quick-view.css`、`demo-home.css`、`demo-site-parts.php`、`functions.php`等被多个模块共用。功能分工不同不代表能同时改同一文件。

1. 接手窗口先报模块编号、确切文件清单、会触及的共享文件。
2. 已被当前窗口占用的文件不直接改；先在自己的D盘任务目录产出独立资产/草稿/补丁，由本窗口整合挂载。不要把整个旧主题覆盖回来。
3. 新增样式按模块独立命名，限定DOM根，避免全站a/button/img/h2等宽泛选择器。新增交互独立helper，挂载仍由原入口统一管理。
4. 主题前端在 `D:/Codex/Projects/peptide-platform-worktrees/frontend`；后端目录不编辑。主仓库只做正常整合，不覆盖peer的在途文件。
5. 每个窗口交付：改动清单、后台字段/接口需求、实际手机截图、验证与限制、未完事项。Git推送与本机装修发布不等于公网部署。

### M05后端接口边界

前端不算满减资格、不替换插件开关、不造推荐报价。活动/推荐报价、券应用与确认、购物车、库存来自原生权威。本轮用既有主题同SKU只读card DTO补齐比较价：全部ID/单价/币种/小数位必须匹配原有效报价，并重验generation/快照/过期/非pending；失败保留原推荐，不造原价。后端quoted DTO可选`regularUnitPrice:{minor,text}`仍可作为未来减少一次GET的优化，并非当前展示的阻塞项。商品行、最近浏览和推荐这次都不需要另做后端插件。
