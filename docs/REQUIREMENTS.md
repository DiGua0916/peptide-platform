# 需求基线

## 已确认

- 用户是大学生，计划参加省级技能大赛。
- 项目为面向海外的多肽独立站。
- 用户提出以色列实验室团队、中国源头厂家、美国本地仓库的业务背景。
- 建站平台采用自托管 WordPress。
- Codex 负责前端设计和开发，Claude 负责后端开发。
- 源铺可作为模板候选来源；曾查看 Lunira、Genesis Lab。
- 本地协作仓库已建立并迁移至 D 盘，当前进行 Claude 首次项目交接。
- 所有新项目、任务工作文件和交付物均使用 D 盘。
- 本项目使用一份本地 Markdown 记录渲染聊天室；用户、Codex、Claude 共用。每次完成项目任务后，助手必须在最终回复前写入进度。用户于 2026-10-11 另行授权独立多群、成员管理及群内实时文字回复：显式选择助手或 @ 后，通过本机官方登录调用 Codex / Claude Code；每群独立文档。不会自动接管已有桌面任务或无限触发助手互聊。

## 待确认

| 事项 | 对实施的影响 |
| --- | --- |
| 比赛名称、赛项、截止时间、评分和 AI/模板使用规定 | 功能范围、交付形式和工作计划 |
| 产品类别、用途和目标客户 | 产品字段、内容与采购流程 |
| 现有业务资源及可公开资料 | 团队、厂家、仓库页面的可验证内容 |
| 比赛演示或真实运营 | 支付、邮件、库存、隐私和上线范围 |
| 最终品牌与页面文案 | 主题视觉、域名与内容 |
| 最终模板及可用源码、授权 | 原生主题或静态模板改造 |
| 是否需要 WooCommerce | 产品、库存、订单的数据来源 |
| 本地 PHP/数据库运行方式 | 可复现开发与测试 |
| GitHub 账号与远程仓库要求 | 远程备份、访问和协作配置 |

## 可讨论的首版流程

产品检索 → 查看规格和批次资料 → 提交询价 → 后台处理 → 查询履约状态。

此流程是前期建议，不代表用户已逐项批准全部功能。先确定目标客户和比赛要求，再排实现优先级。

## 内容原则

真实声明应有来源。演示信息明确标注，不将模板内的人物、成果、评价、资质或统计数字当作项目事实。不预设多肽的用途分类或人体功效。

## 当前交付边界

仓库初始化不包含 WordPress 安装、付费模板下载、域名购买、云服务发布、收款或 Claude 自动调用。
